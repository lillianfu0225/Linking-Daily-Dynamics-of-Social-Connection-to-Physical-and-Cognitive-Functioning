## Statistical Code & Data Management

Statistical code — including data management code required to create composite variables — for all published papers is organized by study in this repository (see folders above) and archived with a permanent DOI via our [Zenodo record](https://zenodo.org/) at the time of each publication.

Each study folder contains:
- A `README.md` describing that study's variables, composite construction, and analysis approach
- Data management scripts used to build composite variables from raw biomarker and self-report data
- Statistical analysis code corresponding to the published results

Together with the linked publications and OSF registrations, this documentation is intended to provide sufficient information for anyone to access the publicly available data and replicate the data management and analysis procedures.
